# Security Policy

## Supported Versions

Only the latest release receives security fixes.

Please upgrade to the newest version (`npm install -g nunchuk-cli@latest`)
and confirm the issue still exists before reporting.

## Reporting a Vulnerability

Please do NOT report security vulnerabilities through public GitHub issues.

Instead, report them via:

- GitHub Private Vulnerability Reporting (Security and quality tab → "Report a vulnerability"), or
- Email: security@nunchuk.io

Please include:

- Description of the vulnerability and potential impact
- Steps to reproduce or proof-of-concept
- Affected versions

You will receive an initial response within 72 hours.

## Disclosure Policy

We follow coordinated disclosure. Please allow up to 90 days for a fix
before public disclosure. We will credit reporters in release notes
unless anonymity is requested.
